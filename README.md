# Shoot Me Pls

A Godot 4 first-person bean survival shooter.

## Open the project
1. Install Godot 4.3 or newer.
2. Clone or download this repository.
3. Open the folder containing `project.godot` in Godot.
4. Press F6 only for a selected scene, or F5 to run the project.

## Controls
- WASD: move
- Mouse: aim
- Left click: fire
- R: reload
- Space: jump
- Shift: sprint
- Ctrl: toggle crouch
- B: open/close weapon shop
- Escape: release mouse

## Gameplay
Defeat beans to earn $10-$36 each. Spend cash in the field armoury on ammunition, health, damage and fire-rate upgrades. Ammo and health pickups can appear around the arena.

All current models and materials are generated in GDScript, so no external asset packs are required for the prototype.

## Current build
This is the first playable foundation. The models are procedural placeholders rather than imported high-detail art assets. Run it in Godot and report any errors from the Output panel so they can be fixed in the next pass.
