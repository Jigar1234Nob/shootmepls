# Third-party asset sources

This tactical pass currently uses procedural Godot meshes for the bean silhouettes, rifle and arena props. This keeps the game self-contained and avoids runtime hotlinks.

External packs suitable for imported models and materials:
- [Kenney Blaster Kit](https://kenney-assets.itch.io/blaster-kit) - CC0 1.0 weapon and target models, including glTF.
- [Kenney Factory Kit](https://kenney.nl/assets/factory-kit) - industrial machinery and warehouse props; verify the pack's current licence before importing.
- [Poly Haven Concrete](https://polyhaven.com/a/concrete) - CC0 PBR concrete material maps.

Keep each downloaded pack's licence file and record the exact pack version here. Never hotlink asset files at runtime.
